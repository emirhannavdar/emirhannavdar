# ⭐ Featured Projects

## 🔌 Modbus PLC Simulator

**[View Repository →](https://github.com/emirhannavdar/modbus-plc-simulator)**

A Python-based **Modbus/TCP PLC process simulator** designed for development and testing without requiring physical PLC hardware.

### Key Features

* Modbus/TCP server implementation using PyModbus
* Structured holding-register mapping
* 32-bit values represented across Modbus registers
* Manual and automatic operating modes
* Motor state-machine logic
* RPM simulation
* Pressure simulation
* Current and temperature simulation
* Alarm and fault-code handling
* Emergency-stop logic
* Heartbeat and runtime tracking
* Simulated process dynamics
* Configurable scan cycle
* Process limits and protection logic
* Structured logging and state monitoring

The project is designed to provide a realistic software-based environment for testing Modbus clients and PLC-style process behavior.
